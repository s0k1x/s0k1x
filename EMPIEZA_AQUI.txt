S0K1X NEBULA CORE — QUICK INSTALL
==================================

IMPORTANT: Upload the CONTENTS of this folder into your existing repository
https://github.com/s0k1x/s0k1x
Do not upload the ZIP itself, and do not put everything inside another folder.

1) Extract the ZIP on your computer.
2) Open the extracted folder.
3) In your GitHub repository, choose Add file > Upload files.
4) Drag in README.md, .gitignore, and the folders arcade, assets, scripts, .github.
   If the browser will not upload folders, use GitHub Desktop or Git from a computer.
5) Commit the changes to your repository's default branch.

AUTOMATIONS
- Open the repository's Actions tab.
- If prompted, enable workflows.
- Run "Update Cyberpunk Profile" using Run workflow to refresh the repository table.
- "Validate Profile" checks README structure and Python scripts.

ARCADE / GITHUB PAGES
- Open Settings > Pages.
- Under Build and deployment, choose GitHub Actions.
- Open Actions > Deploy Cyber Snake Arcade > Run workflow.
- When deployment succeeds, the game should be at:
  https://s0k1x.github.io/s0k1x/

NOTES
- GitHub README does not run custom JavaScript/CSS. The game is a separate Pages site.
- If your default branch is not named main, adjust the branch filter in
  .github/workflows/deploy-arcade.yml to your default branch before relying on
  automatic deployment. You can still manually run the workflow.
- External badge/statistics services may sometimes be slow or temporarily unavailable.
